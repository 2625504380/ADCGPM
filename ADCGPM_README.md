# ADCGPM

This is a demo of the Adaptive Derivative-Free Conjugate Gradient
Projection Method (ADCGPM) for solving large-scale constrained nonlinear
equations

\[ F(x)=0,`\quad `{=tex}x`\in `{=tex}C, \]

where (C) is a nonempty closed convex set.

The proposed algorithm is based on a memoryless BFGS-inspired conjugate
gradient projection framework together with enhanced self-adaptive line
search techniques. It can also be applied to image restoration and
sparse signal recovery.
